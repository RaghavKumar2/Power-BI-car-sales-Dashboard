# Power-BI-car-sales-Dashboard
🚗 Car Sales Analytics Dashboard | Power BI Project

## 📊 Overview
This repository contains a **Car Sales Analytics Dashboard** built in **Power BI**.  
The dashboard provides insights into sales performance, customer demographics, and regional distribution.  
It is designed to help business stakeholders identify trends, optimize strategies, and make data-driven decisions.

---

## 🧩 Dataset Summary
**Source:** Kaggle
**Records:** 23,906 transactions  
**Period Covered:** January–February 2022  

**Key Columns:**
- `Date`, `Customer Name`, `Gender`, `Annual Income`
- `Dealer_Name`, `Dealer_Region`, `Company`, `Model`
- `Transmission`, `Color`, `Price ($)`, `Body Style`
- `MonthName`, `Sales Quantity`, `Income Range`

---

## 📈 Dashboard Features
1. **KPI Cards** → Show total sales, average price, auto vs. manual cars sold, and overall revenue.  
2. **Monthly Sales Trend** → Line chart tracking growth patterns and seasonal peaks.  
3. **Dealer Region Map** → Interactive map highlighting top-performing regions.  
4. **Customer Demographics** → Income range and gender analysis to understand buyer segments.  
5. **Company-Wise Sales Comparison** → Ranking of car brands (Chevrolet, Dodge, Ford, Toyota, etc.) with clear visualization.  

---

## 💡 Key Insights
- Auto cars slightly outperform manual cars in total sales.  
- Pale White color dominates customer preference.  
- Chevrolet leads in total units sold.  
- Income range 0–100K shows strong engagement, suggesting affordability drives volume.  
- Regional hotspots indicate potential for targeted marketing.  

---

## 🛠️ Tools & Techniques
- **Power BI Desktop** for data modeling and visualization  
- **Power Query** for data cleaning and transformation  
- **DAX Measures** for KPI calculations  
- **Map Visualization** using Bing integration  
- **Bar, Line, and Pie Charts** for comparative insights
